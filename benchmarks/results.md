# Anonymization benchmark

Generated by `just gateway-bench` on 2026-09-30, Intel(R) Core(TM) i7-14700KF, 28 threads, CPU only. Do not edit by hand: rerun the command.

Dataset: [`dataset.jsonl`](dataset.jsonl), 100 synthetic French texts (letters, emails, messages, forms) with 508 personal data items, generated by [`generate_dataset.py`](generate_dataset.py).
Presidio runs as the `pii-fr` guardrail does: the 11 entity types of `config/litellm.yaml`, score threshold 0.4, overlapping detections merged. The LLMs get the same types in a prompt and answer in JSON through Ollama, temperature 0; their spans are merged the same way.

## Latency added by the guardrail
